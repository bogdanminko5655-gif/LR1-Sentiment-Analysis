# Дані

Під час першого `python main.py` автоматично завантажується `imdb_labelled.txt` з офіційного корпусу **UCI Sentiment Labelled Sentences**, автори Kotzias et al. (2015).

Посилання: https://archive.ics.uci.edu/dataset/331/sentiment+labelled+sentences
DOI: https://doi.org/10.24432/C57604
Ліцензія набору: CC BY 4.0.

Якщо автоматичне завантаження не працює: завантажте ZIP з наведеної сторінки та скопіюйте `imdb_labelled.txt` у цю папку.
Формат кожного рядка: `англійський текст<TAB>0` або `англійський текст<TAB>1`.

Не змішуйте українські речення зі стандартним англомовним IMDb-корпусом для тестування якості: потрібні українські дані та відповідні стоп-слова/стемер.
